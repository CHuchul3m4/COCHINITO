Que es este proyecto

Es un proyecto creado por diversión, trata de solucionar un problema real como lo es la administración de gastos, y aunque no es perfecto, es un proyecto que me gusta y me hace sentir orgulloso. Nunca me lo pidieron, y nunca me lo van a evaluar ni pagar por él, pero es mi proyecto y me gusta, y eso es lo que importa, que me guste a mí y que me haga sentir orgulloso de mí mismo.

Como funciona por dentro y licencias

Este proyecto está licenciado bajo la Licencia Apache 2.0. Puedes encontrar más información sobre la licencia en el archivo LICENSE.

El proyecto está desarrollado en HTML, CSS y JavaScript, utilizando tecnologías web estándar. No se utilizan frameworks externos, lo que permite un mayor control sobre el código y la personalización del proyecto.

El código fuente del proyecto está disponible en el repositorio de GitHub. Puedes acceder al repositorio para ver el código, realizar contribuciones o informar sobre problemas.

El proyecto es mío, libre y está en desarrollo; no tiene malware y puedes verificarlo por ti mismo, tampoco espiamos gente.

Qué pretendo con este proyecto

El principal objetivo es crear una solución práctica para la administración de gastos, generalmente dirigido para estudiantes de universidad aunque realmente cualquier persona puede usar esta porquería.
